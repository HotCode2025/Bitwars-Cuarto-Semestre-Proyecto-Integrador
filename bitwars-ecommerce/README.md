# Proyecto: E-commerce Tienda de Deportes (Bitwars)

**Brief del Proyecto:**
Desarrollo de un E-commerce para una tienda de deportes con las siguientes funcionalidades:
- Registro y autenticación de usuarios.
- Catálogo de productos con vista 360° (camisetas).
- Carrito de compras nativo.
- Integración con Mercado Pago (Checkout Pro).
- Cálculo de envíos con Correo Argentino.
- Panel de administración (Stock, Productos, Órdenes).

**Stack Tecnológico:**
- Backend: Java + Spring Boot + Spring Security (JWT).
- Frontend: React (Node.js).
- Base de Datos: PostgreSQL alojada en Neon.
- Despliegue: Frontend en Netlify, Backend en Render/Railway.
